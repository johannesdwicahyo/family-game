# Huddle 1.1 — seven new games (design)

Builds on Huddle 1.0 (commit cd1b0f1, 9 games, approved v3 look: light, grown-up flat editorial art, Bricolage Grotesque display type, `art/STYLE.md`). Approved by the owner in chat on 2026-10-24. 1.0 ships first; 1.1 adds 7 games → 16.

## Shared rules (all games)
- Same architecture and patterns as the existing games (Coordinator + Game model + Views, `GameDefinition` registry, shared player names, no-repeat picking per language across sessions, Feedback sounds/haptics, `-screen` debug states, v3 design system, setup header with art).
- Indonesian and English, written naturally (not literal translation), Indonesia-flavoured content first.
- **Family-safe for a 12+ rating**: no sexual content, alcohol/drugs, gambling, religion, ethnicity/SARA, politics, self-harm, or anything that humiliates a player. Adults and young adults are the main audience — witty, not childish.
- Ads only between games (existing rule). No timers or prompts that pressure players physically.
- Each game: card art in the approved v3 style via the game-assets-enhancement skill + `tools/fal.sh` (edit against the v3 anchor), unit tests for its logic, added to the UI play-through test, `docs/content-sample.md` section updated.
- Game ids/colours: pick accents that are distinct from the existing 9 and pass WCAG AA (as in 1.0).

## The games
1. **ABC Lima Dasar** (classic, paper & pen) — everyone shows fingers on "A-B-C-Lima-Dasar!", host enters the total (or taps a random-letter button), app counts the alphabet to the letter with an animation. Fixed categories (default: Nama, Hewan, Kota, Buah/Makanan, Benda; editable, presets). Timer (60–120 s). Then round-by-round scoring: for each category, host marks each player's answer as unique (10), same as someone (5) or empty/invalid (0); totals over rounds; skip hard letters (X, Q, Z… configurable). 2–12 players.
2. **Kategori Kilat** (fast, pass-the-phone) — a category is shown ("Merk mie instan", "Hewan berkaki empat"); the phone passes player to player; each must say a new answer before their short timer runs out (tap ✓ to pass on; group judges repeats with a ✗ button); out on fail; last one standing wins the round; points across rounds. ≥ 250 categories per language, all with plenty of answers.
3. **Kata Terlarang** (Taboo) — two or more teams; describer sees a word + 5 forbidden words; buttons Benar / Lewati / Terlarang (buzz); 60 s rounds; team scores; configurable target score. ≥ 400 cards per language, themed (Umum, Indonesia, Makanan, Hiburan, Tempat, Pekerjaan…), theme filter.
4. **Tebak Gaya** (charades) — teams; actor sees a word, acts silently; Benar/Lewati; optional tilt-to-answer like Who Am I (reuse its motion code if present, else buttons); 60 s rounds; themes: Film & Lagu (titles only, widely known), Hewan, Profesi, Kegiatan Sehari-hari, Olahraga, Indonesia (tradisi, makanan, tempat). ≥ 300 per language.
5. **Werewolf** — phone is the narrator for 5–12 players. Roles: Warga, Serigala (1–3 by count), Peramal (Seer), Dokter; optional Pemburu (Hunter) and Penyihir (Witch) toggles. Flow: private role reveal pass-around → night (pass the phone; each player taps through a private screen so nobody can tell roles by tap length — everyone does a dummy action) → morning announcement → discussion timer → vote (pass-around or host tally) → elimination with optional role reveal → win check. Clear rules screen, a moderator log for the host at the end. Narration text that's atmospheric but short. Unit tests for the night resolution and win conditions.
6. **Trivia (with themes)** — themes: Indonesia, Sejarah, Sains & Alam, Film & Musik, Olahraga, Makanan & Minuman, Geografi Dunia, Pengetahuan Umum; mixed mode. Multiple choice (4 options), individual or teams, buzz order by passing or host-picks-who-answered, scoreboard, short explanation after each answer. **Accuracy is critical**: only stable facts (no "current" office-holders, records, prices, populations that change), each question checked; a test asserts every question has exactly one correct option and a source/explanation field. ≥ 60 per theme per language (≥ 480 each).
7. **Truth or Dare (Jujur atau Tantangan), with themes** — themes: Teman, Keluarga, Kantor/Kampus, Pasangan (sweet and fun, never sexual), Seru Banget (sillier). Players take turns; choose Jujur or Tantangan; card shown; "Lewati" allowed (limited skips per player, optional). Dares are safe, doable in a living room, no food/drink challenges with alcohol, nothing dangerous, nothing posting to social media without consent, nothing that singles out appearance. ≥ 120 truths + 120 dares per theme per language.
